À propos

Un éditeur de métadonnées local et monofichier, pensé pour GitHub Pages.

MetaData

L'application fonctionne dans le navigateur, tout en distinguant deux stratégies d'écriture : l'édition intégrée lorsque le format peut être réécrit directement, et le mode sidecar universel lorsque ce n'est pas possible.

Le mode sidecar génère un fichier .metadata.json - ou une archive .zip contenant le fichier original et ses métadonnées - pour les formats non réécrits nativement dans le navigateur.
