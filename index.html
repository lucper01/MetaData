À propos

Metadata Editor

Metadata Editor

Une application web locale pour inspecter, modifier, exporter et nettoyer les métadonnées de fichiers courants.

JPEG, PNG, PDF, MP3, DOCX, XLSX, XLSM et PPTX sont éditables. Les autres formats restent consultables lorsque le navigateur sait les prévisualiser.

Principe

Le fichier original n'est jamais écrasé. Toute modification génère une nouvelle copie à télécharger.
